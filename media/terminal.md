### Terminals

Choose **Open Terminal in Dev Container** from the Dev Container actions or Command Palette.
The extension uses the user, working directory, shell, and environment resolved by setup.
You can also explicitly select the extension's **devcontainer** profile in the terminal dropdown.

Regular **Terminal > New Terminal** opens in the outer workspace container (UDI), where cluster
tools such as `oc` and `kubectl` remain available. The extension does not change your default profile.
